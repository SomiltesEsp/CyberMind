# Phase 1: Foundations 🧱

Esta es la primera fase del viaje. Aquí construimos los cimientos técnicos necesarios antes de entrar de lleno al hacking o defensa avanzada.

## Objetivos
1.  **Programación en Python:** Comprender la sintaxis básica, estructuras de control, funciones y manejo de dependencias. Capacidad de crear scripts de automatización.
2.  **Sistemas Operativos (Linux):** Desenvolverse cómodamente en la terminal (CLI), gestionar permisos, entender la jerarquía del sistema de archivos y escribir pequeños scripts en Bash.
3.  **Redes Básicas:** Entender cómo se comunican las computadoras (Modelo OSI, TCP/IP, Puertos, HTTP/S).

## Proyectos a Desarrollar
*   [ ] **Generador de Contraseñas Seguras (Python)** - Manejo de strings, librerías estándar y lógica de negocio.
*   [ ] **Escáner de Puertos Básico (Python)** - Interacción con sockets de red.
*   [ ] **Configuración de un servidor local (Linux/Bash)** - Setup automatizado básico mediante scripts.
